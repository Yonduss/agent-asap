# Agent ASAP

Agent ASAP is a planned Python CLI that turns a short project brief into a small, runnable starter the developer can understand and extend. It sets up one complete user flow and shows the developer where to make the next change.

## Status

The project is in the planning stage. The first demo will scaffold a local task list with one HTML/CSS page, a small Python backend, and SQLite. The generated project will include a short brief, instructions to run it, and a check that a new task stays in the list after a refresh.

The first milestone uses local templates to generate the starter without model calls. A later milestone will test whether a model helps turn an open-ended brief into a well scoped starter.
